# 📰 Blog Management System (Django + React + Markdown)

This is a **Blog Management System** project built with:

- **Backend:** Django (Python)
- **Frontend:** React (Vite)
- **Database:** SQLite (default, easy to migrate to MySQL/PostgreSQL)
- **Features:** Markdown support for articles, API + frontend integration
